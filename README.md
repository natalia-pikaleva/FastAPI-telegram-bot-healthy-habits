# Телеграм чат-бот Healthy Habits

## Описание:

Чат-бот для Телеграм позволяет пользователю организовать удобный трекинг привычек. Теперь изменить свой образ жизни
легко и приятно!  
Удобное развертывание на любом сервере с Docker.

## Возможности бота:

- [ ] Создать новую привычку
- [ ] Установить время напоминания для каждой привычки отдельно
- [ ] Изменить параметры привычки
- [ ] Удалить привычку
- [ ] Получить список всех привычек с возможностью отметить выполненные за сегодня прямо в списке
- [ ] Получить список всех привычек без отметки за сегодня с возможностью проставить отметку
- [ ] Если установлено время напоминания, бот будет отправлять сообщение о том, что пора выполнить привычку. Можно
  поставить отметку о выполнении прямо в напоминании. Причем напоминания будут приходить только о привычках, по которым
  отметка за сегодня еще не установлена
- [ ] Получить удобную статистику о выполнении привычек за последние 7 дней (по всему списку привычек), за последние 21
  день по конкретной выбранной привычке

## Подготовка и запуск чат-бота

1. Клонируйте репозиторий
2. Убедитесь, что на вашем сервере установлен Docker и база данных PostgreSQL
3. Создайте в корне репозитория файл .env и заполните его по шаблону .env.template:

- BOT_TOKEN - токен, который вы получаете при создании бота в чате Телеграмм @BotFather
- DB_USER - имя пользователя для подключения к вашей базе данных
- DB_PASSWORD - пароль для подключения к базе данных
- DB_NAME - название базы данных, например, healthy_habits_db
- DB_HOST=postgres - если вы захотите изменить хост базы данных, необходимо будет внести изменения в файл
  docker-compose.yaml
- SECRET_KEY - секретный ключ для создания токена
- ALGORITHM - алгоритм шифрования токена, например, HS256
- ACCESS_TOKEN_EXPIRE_MINUTES - время действия токена в минутах, например, 30
- API_HOST - хост, на котором размещается FastAPI, например, 0.0.0.0. Если размещаете на сервере, используйте хост
  вашего сервера

4. В корне проекта в терминале соберите и запустите приложение командой:  
   ```docker compose up --build```
   При следующих запусках можно использовать команду:  
   ```docker compose up```
5. Перейдите в Телеграмм в ваш чат-бот, название которого вы указали при получении токена для бота и нажмите кнопку
   Start. Чат-бот готов к работе

## Возможности для расширения функционала бота:

- Можно указать дату начала действия привычки, например, с 01.06.2025 и тогда далее переписать логику так, чтобы
  учитывать дату отсчета. На данный момент указанная дата отсчета не влияет на процессы
